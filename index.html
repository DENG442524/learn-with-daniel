Make your first webpage

A webpage is built in layers. These three technologies are a friendly place for beginners to start.

🧱

1. HTML: the structure

HTML uses elements to organise content. A heading can use <h1>, a paragraph can use <p>, and a link can use <a>.

🎨

2. CSS: the appearance

CSS controls colours, spacing, text, and page layout. It helps make the same HTML content clear and pleasant to use.

⚙️

3. JavaScript: the interaction

JavaScript can respond to actions, such as clicking a button. Begin with HTML and CSS, then add interaction when you are ready.

Try this first project

Create a page about a hobby: add a title, a short introduction, three things you enjoy, and one useful link. Then use CSS to choose colours and arrange the content. Preview it on a phone screen as well as a computer.

Understand and explore AI

Artificial intelligence (AI) describes computer systems that perform tasks that usually need human-like abilities, such as recognising patterns or understanding language.

How can a simple AI project work?

  • 1 Choose one small task, like sorting example items into groups.
  • 2 Gather suitable examples and check that they are accurate.
  • 3 Use a beginner-friendly learning tool to train or configure a model.
  • 4 Test it with new examples and note where it gets things wrong.

Use AI thoughtfully

AI tools can make mistakes and reflect problems in their examples. Check important answers with a trusted source, protect personal information, and ask a teacher or trusted adult before sharing data or publishing a project.

A good first activity is to compare how a person and a simple sorting rule group the same set of objects. You can learn about patterns without needing to build a large AI system.

SS1 science: start with the basics

Science helps us ask questions, investigate evidence, and explain the world. These introductory topics are common starting points; follow your teacher's scheme of work for your class.

🌱

Biology

Topic: Living things

Living things carry out life processes such as nutrition, respiration, growth, and reproduction. Practise by observing a plant and recording how it changes over several days.

⚗️

Chemistry

Topic: Matter and particles

Matter has mass and occupies space. Solids, liquids, and gases behave differently because their particles are arranged and move differently.

🏃

Physics

Topic: Measurement and motion

Measurements use agreed units. For example, speed describes distance travelled per unit of time. Measure a short walk safely and compare the results.
